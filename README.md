# Aim
To detect and compare edges in an image using different edge detection techniques.

# Software Used
- Python
- Google Colab
- OpenCV
- NumPy
- Matplotlib

# Techniques Used
1. Sobel Edge Detection
2. Prewitt Edge Detection
3. Roberts Edge Detection
4. Canny Edge Detection

# Description
This program reads a grayscale image and applies four different edge detection techniques. The detected edges are displayed along with the original image for comparison.

## Input
The input image used in this program is:

`nature.jpg`

Make sure the image is uploaded to the Google Colab working directory before running the program.

# Output
The program displays five images:
- Original grayscale image
- Sobel edge detection
- Prewitt edge detection
- Roberts edge detection
- Canny edge detection      

# How to Run
1. Open Google Colab.
2. Upload `nature.jpg`.
3. Copy and run the Python code.
4. The edge-detected images will be displayed.

# Result
Different edge detection techniques successfully identify the edges and boundaries present in the nature  image.
